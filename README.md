# Sensor Calibrator — Android MVP

Первая версия приложения для диагностики датчиков Android

## Что реализовано
- Список доступных датчиков: акселерометр, гироскоп, магнитометр, приближение, освещённость, барометр.
- Показания датчиков в реальном времени.
- Компас на основе магнитометра и акселерометра.
- Инструкция по калибровке компаса движением «восьмёркой».
- Базовый экран диагностики.

## Важно
Обычное Android-приложение не может менять заводские коэффициенты калибровки датчиков или выполнять сервисную калибровку прошивки. Оно может читать показания, оценивать доступность/точность и выполнять пользовательскую программную обработку. Для магнитометра Android сообщает статус точности через `onAccuracyChanged`.
Минимальная версия Android: 8.0 (API 26). Целевая версия: Android 15 (API 35).

## Примечание о компасе
Направление зависит от магнитных помех и ориентации устройства. Для сравнения с истинным севером может потребоваться учитывать магнитное склонение, которое MVP пока не рассчитывает.
